# Brand marks (SVG)

Converted from the 2022 EPS kit (`652_WSMC_Logo_005_*.eps`) via Ghostscript font-outlining + path extraction.

| File | Lockup | Typical use |
|---|---|---|
| `abbreviated.svg` | Arch + WS/MC stack | Primary header logo |
| `mark.svg` | Arch only | Favicon, small sizes, mobile |
| `acronym-stacked.svg` | WS/MC only | Compact wordmark |
| `acronym.svg` | WSMC horizontal | Alternate wordmark |
| `full.svg` | Arch + full name + NYU Graduate Group | Footer, cover sheets |

Colour with CSS `color` / `currentColor`. On light grounds use brand purple `#7850AA`; on dark grounds use white or `#A78BC9`.

Do not use the PNG exports in `26-27/` — they have opaque arch fills and matting residue.
